the authoring idiom — literal JSON in the template

{
  "xAxis": { "type": "category", "data": ["Q1", "Q2", "Q3", "Q4"] },
  "yAxis": { "type": "value" },
  "series": [{ "type": "bar", "name": "Revenue", "data": [12.4, 13.1, 13.9, 15.2] }]
}

No tooltip, no legend, no aria in the source — the feature adds all three, and only where the author did not.

degradation — a spec that is not valid JSON

{
  "xAxis": { "type": "category", "data": ["Q1", "Q2", "Q3"] },
  "yAxis": { "type": "value" },
  "series": [{ "type": "bar", "data": [12, 14, 13], }]
}

Invalid on purpose: one trailing comma. The card never renders, the source shows instead with a red border, and the engine is not downloaded on its account. This is the only state of this component that cannot be seen any other way.
