requirement

three requirements — a must, a should, and an explicit won't

REQ-014

A report is regenerated, never edited

Must
Description
The controller rebuilds the whole page from source data on every run. No published page is patched in place.
Fit criterion
Rebuilding an unchanged report twice produces two byte-identical files.
REQ-021

Every figure names the filing it came from

Should
Description
Each statement block carries the period and the form type behind its numbers.
Fit criterion
A reader can trace any printed figure to a filing in one step, without leaving the page.
REQ-033

Intraday price updates

Won't
Description
Reports are built against filings and close prices. Live quotes are out of scope for this release.
Fit criterion
No component reads a quote endpoint at render time.
